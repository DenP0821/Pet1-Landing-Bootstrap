Данный мини-проект - первый опыт. :relaxed:  

На момент начала работы я имел базовые представления о HTML и CSS, и только начинал осваивать JavaScript.  

Идея создания лендинга возникла, когда я узнал о Bootstrap и захотел его "прощупать" + Знакомому на тот момент человеку требовался лендинг для рекламы его занятия частным психологом.  

Я решил - что это хороший начальный опыт. Ведь на одной теории далеко не уедешь. :grin:
